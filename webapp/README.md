# 简云音乐网页版

这是 Android 版简云音乐的独立 Web/PWA 实现，复刻发现、搜索、我的音乐、歌单详情、播放页和设置弹层，并保留浏览器端收藏、最近播放、用户歌单、主题、背景、播放列表、睡眠定时等功能。

## 静态部署

网页已经改为纯静态版本。把 `public` 文件夹中的全部文件上传到虚拟主机的网站根目录即可，不需要 Node.js、数据库或常驻后端进程。

如果上传到二级目录也可以正常使用，页面资源均采用相对路径。

## 在线音乐

- 未绑定并验证卡密时，发现页、在线搜索和播放均不会请求或显示在线数据。
- 绑定成功后，可切换酷狗、酷我、QQ、网易云四个来源；浏览器直接访问对应在线接口，不消耗虚拟主机计算资源。
- 播放需在“我的 → 设置 → 在线音乐来源”中输入用户自己的聆澜卡密。
- 项目不包含任何预置卡密；卡密只保存在当前浏览器的本地存储中，并仅在校验和获取播放地址时直连聆澜服务。
- 搜索及播放可用性受第三方接口、版权、会员和地区限制影响。

## PWA

在支持 PWA 的浏览器中可使用“安装应用”添加到桌面。核心页面资源会离线缓存，在线搜索与播放仍需网络。
